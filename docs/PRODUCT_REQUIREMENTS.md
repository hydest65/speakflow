# SpeakFlow 产品需求文档 PRD

## 1. 产品定位

SpeakFlow 是面向中国成人英语学习者的真实视频英语听说训练网站。

核心主张：

> 跟着真实视频，把英语说出来。

产品重点解决：

- 听不懂真实英文视频。
- 学过多年英语但开不了口。
- 缺少每日训练节奏和反馈。

## 2. 目标用户

- 上班族：需要日常、职场和商务沟通英语。
- 出国和旅行人群：需要酒店、机场、点餐、问路等真实场景表达。
- 学过多年英语但听说薄弱的人：有基础，但卡在真实语速和口语输出。

## 3. 核心页面

- 视频库：默认入口，展示今日状态、今日任务、推荐视频、筛选和视频列表。
- 收藏夹：收藏视频，并从视频库同步显示用户保存的复习清单。
- Tips：按视频拆解单词、短语和地道表达，帮助用户沉淀可复习素材。
- AI陪练：固定真实场景角色对话，提供文字输入、模拟反馈，并通过后端代理接入真实模型。
- 会员：承载年度会员权益和本地学习记录。
- 跟读训练页：从视频库进入，使用视频、逐句字幕、跟读评分三栏结构。

## 4. 顶部导航

固定顺序：

1. 视频库
2. 收藏夹
3. Tips
4. AI陪练
5. 会员

学习记录不单独放顶部导航，统一合并到会员页。

## 5. MVP 范围

当前静态原型先完成：

- 新导航结构。
- 视频库入口页。
- 收藏夹页面。
- Tips 页面。
- AI陪练页面。
- 会员页内嵌学习记录。
- 跟读训练页三栏结构。
- Render 静态站部署配置。

后续再接入：

- 真实视频资源。
- 录音上传。
- 更完整的 AI 评分和真实语音入口。
- 登录和年度会员支付。
