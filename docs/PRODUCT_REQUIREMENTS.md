# SpeakFlow 产品需求文档 PRD

## 1. 产品定位

SpeakFlow 是面向中国成人英语学习者的真实视频英语听说训练网站。

核心主张：

> 跟着真实视频，把英语说出来。

产品重点解决：

- 听不懂真实英文视频。
- 学过多年英语但开不了口。
- 缺少每日训练节奏和反馈。

## 2. 目标用户

- 上班族：需要日常、职场和商务沟通英语。
- 出国和旅行人群：需要酒店、机场、点餐、问路等真实场景表达。
- 学过多年英语但听说薄弱的人：有基础，但卡在真实语速和口语输出。

## 3. 核心页面

- 视频库：默认入口，展示今日状态、今日任务、推荐视频、筛选和视频列表。
- 收藏夹：收藏视频，并从视频库同步显示用户保存的复习清单。
- Tips：按视频拆解单词、短语和地道表达，帮助用户沉淀可复习素材。
- AI陪练：固定真实场景角色对话，提供文字输入、模拟反馈，并通过后端代理接入真实模型。
- 会员：承载年度会员权益和本地学习记录。
- 跟读训练页：从视频库进入，使用视频、逐句字幕、跟读评分三栏结构。

## 4. 顶部导航

固定顺序：

1. 视频库
2. 收藏夹
3. Tips
4. AI陪练
5. 会员

学习记录不单独放顶部导航，统一合并到会员页。

## 5. MVP 范围

当前静态原型先完成：

- 新导航结构。
- 视频库入口页。
- 收藏夹页面。
- Tips 页面。
- AI陪练页面。
- 会员页内嵌学习记录。
- 跟读训练页三栏结构。
- Render 静态站部署配置。

后续再接入：

- 真实视频资源。
- 录音上传。
- 更完整的 AI 评分和真实语音入口。
- 登录和年度会员支付。

## 6. 0.1.4 产品状态补充

- 首页视频库当前以 8 个 TED 语言学习相关素材作为原型测试内容。
- TED 素材仅使用官方嵌入链接和来源说明，不下载、不剪辑、不重新托管视频。
- 学习页当前方向改为参考截图式双栏布局：左侧视频和简介，右侧动态字幕列表。
- 逐词精读暂时从学习页移除，避免首屏过挤；后续等字幕数据规范稳定后再重新设计。
- 字幕解析当前只作为实验性能力保留，下一版优先重做字幕数据来源、格式和渲染规范。
## 7. 0.1.5 产品状态补充

- 新增“字幕批注”工作台，用户可以输入视频直链或选择本地视频，生成带时间轴的字幕列表和学习备注。
- 字幕批注页支持点击字幕时间点跳转视频、手动编辑字幕文本和 AI 备注，并导出 Markdown、Word、SRT、VTT、JSON。
- 当前真实可用范围优先覆盖 `.mp4/.webm/.mov` 等可直接访问的视频链接；YouTube、B站、TED 页面链接属于下一阶段的平台解析能力。
- 若用户粘贴已有英文稿，系统走手动稿件切分模式，便于低成本测试编辑和导出流程。
- 真实直链解析需要 FFmpeg 与 OpenAI API Key；页面会显示环境诊断，避免用户误以为模拟流程等同于真实语音识别。
## 8. 架构方向补充

- SpeakFlow 后续采用“视频库 + 字幕学习 + 精读卡片 + 学习进度”的资源拆分，而不是把所有内容写死在单个页面里。
- 产品能力可以参考成熟视频学习平台的结构，但界面视觉、品牌表达和学习方法保持 SpeakFlow 自己的方向。
- 基础版不强依赖 AI：用户可以导入/生成字幕、手动编辑备注、保存学习进度和导出资料。
- MiniMax 作为增强层：只在用户主动开启时生成学习备注、词汇/短语/表达卡片或口语反馈。

## 9. 0.2.0 产品方向

- 0.2.0 标志项目从静态原型转向数据驱动的视频学习架构。
- 新学习页先验证核心学习结构：视频在左、可滚动字幕在右、精读卡片在视频下方。
- 0.2 阶段暂不锁定最终 UI 视觉风格，优先稳定视频、字幕、卡片和学习进度的数据边界。
