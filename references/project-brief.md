# SpeakFlow Project Brief

SpeakFlow 是面向中国成人英语学习者的真实视频英语听说训练网站。当前方向是现代 SaaS 工具型学习工作台，而不是培训机构宣传落地页。

## 当前产品方向

- 默认入口是视频库。
- 顶部导航顺序：视频库 / 收藏夹 / Tips / AI陪练 / 会员。
- 学习记录合并到会员页。
- 跟读训练页从视频库进入，不放在顶部主导航。
- 当前版本是静态原型，先验证信息架构和页面体验。

## 当前文件

- `index.html`：视频库。
- `favorites.html`：收藏夹。
- `tips.html`：学习方法。
- `ai.html`：AI陪练。
- `pricing.html`：会员和学习记录。
- `learn.html`：跟读训练页。
- `styles.css`：全局样式。
- `app.js`：字幕高亮交互。

## 设计方向

界面要成人化、干净、任务导向。主色使用深蓝、亮蓝和青色，背景保持冷白和浅灰蓝。不要做夸张营销首屏，也不要做儿童学习 App 风格。

## 已完成到 0.1.2

- 用本地 JS 数据驱动视频库、收藏夹和学习页。
- 视频筛选支持主题、难度、时长和来源。
- 视频卡支持收藏交互，并用 `localStorage` 保存。
- 收藏夹会真实显示已收藏视频。
- 学习页支持通过 URL 参数切换视频内容。
- AI 陪练页支持场景切换、英文输入、本地模拟追问和评分反馈。
- AI 陪练轮次和评分会进入本地学习记录。
- 学习页已放入一个临时 CC0 demo 视频，用于测试播放器流程，后续需要替换成真实英语训练视频。
- Tips 已改成类似表达库的结构：左侧视频列表，右侧按单词、短语、地道表达拆解。
- 项目已从纯静态站升级为 Node Web Service 结构，`server.js` 提供 `/api/ai/chat` 后端代理；前端会在后端不可用时回退本地模拟。
- 部署前已加入 `.env.example` 和 `/api/health`，用于检查 Render 服务和 OpenAI Key 配置状态。

## 下一步建议

继续把静态原型变成可测试体验：

1. 完善今日任务和打卡的本地状态细节。
2. 让会员页的学习记录继续扩展为周报和复习建议。
3. 在 Render 环境变量中配置 `OPENAI_API_KEY`，测试真实 AI 回复。
4. 再考虑 React 化和真实后端。
